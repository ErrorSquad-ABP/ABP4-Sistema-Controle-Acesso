# Definition of Done

Um card esta PRONTO quando:

- [ ] Todos os criterios de aceite do card foram atendidos
- [ ] PR aprovado por pelo menos 1 colega (review feito de verdade)
- [ ] CI verde (build + testes + lint)
- [ ] Testes minimos do escopo passando (unitario, integracao ou widget)
- [ ] Documentacao afetada atualizada (docs/, README, contrato)
- [ ] Demonstravel na Sprint Review
- [ ] Nenhum segredo commitado

Uma historia incompleta volta para o backlog — nao entra em "Concluido".
